# 图片智能重命名和分类工具 (v7.0.2)

本项目是一个基于**视觉语言模型（VLM）**的本地图片自动重命名与分类工具。利用多线程和 API 并发，快速扫描本地杂乱的图片库，生成易读的中文文件名，并将其自动归类到对应的语义文件夹中。

## 核心特性

- 🧠 **AI 视觉分析**：接入豆包视觉大模型（支持自定义切换），准确理解图片内容，生成适合作为文件名的简短中文描述。
- 🗂️ **智能分类系统**：根据 VLM 内容分析、文件名的强特征、图片比例等，将图片归入预设的 18 个清晰的语义类别中（如：人像写真、风景自然、AI 生成、学习资料等）。
- ⚖️ **图片比例检测**：内置专门针对“横屏（壁纸）”和“1比1（头像）”的规则，具有最高优先级，自动分离优质素材。
- ⚡ **高性能并发**：支持多账号并发请求 API，多线程加速 MD5 预扫描处理。
- 🛡️ **数据安全保障**：
  - 双重去重系统（MD5 校验 + 路径记录），防止重复处理。
  - 文件防冲突：自动为重名文件添加递增序号。
  - 配置脱敏：敏感配置和 API 密钥通过独立 `config.json` 加载，代码库完全开源安全。
  - 完善的异常捕获与重试机制（超时控制、限流回避）。

## 安装与配置

### 1. 环境准备

确保你已经安装了 Python 3.10+ 环境。

```bash
# 创建虚拟环境（可选但推荐）
python -m venv .venv

# 激活虚拟环境 (Windows)
.\.venv\Scripts\activate

# 安装依赖
pip install Pillow requests
```

### 2. 配置文件设定

由于项目实现了配置脱敏，启动前需要创建你自己的配置文件：

1. 复制项目中的 `config.example.json`，将其重命名为 `config.json`。
2. 编辑 `config.json`，填入你的实际参数：
   - `accounts`：填入你的火山引擎 API Keys。如果只有一个账号，保留一个即可。
   - `base_dir`：要处理的本地图片库绝对路径（例如：`D:\\MyPictures` 或 `e:\\Picture`）。
   - `api_endpoint` & `default_model`：默认使用了火山引擎的豆包大模型，如需使用其他兼容 OpenAI 格式的接口，可自行更改。

## 使用指南

直接运行主程序脚本：

```bash
python vlm_rename_v5.py
```

启动后，程序会通过终端给出以下交互选项（直接按回车可使用默认设置）：
1. **账号选择**：选择使用特定的 API 账号或双账号并发。
2. **模型选择**：选择要调用的视觉模型。
3. **处理数量选择**：限制单次处理的图片数量（默认 500 张，输入 0 处理全部）。

### 工具说明

- `vlm_rename_v5.py`：主程序脚本，执行去重检测、API 调用、图片移动以及日志记录。
- `vlm_classify.py`：纯分类逻辑模块，支持独立运行以执行无需 API 的纯规则迁移任务。
- `fix_md5.py`：历史记录修复工具。

## 运行日志

处理完成后，程序会在你设置的 `base_dir` 目录下生成：
- `rename_log.json`：成功处理并重命名的详细记录。
- `processed_md5.txt` 和 `processed_files.txt`：去重用的缓存记录。
- `error_log.txt`：如果有处理失败的图片，会在此记录详细错误原因。
