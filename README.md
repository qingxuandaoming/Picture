# 🌟 图片智能重命名和分类工具 (VLM Renamer)

这是一个基于**视觉语言模型（VLM）**的本地图片全自动整理神器。
它通过调用火山引擎的大模型（如豆包等兼容 OpenAI 格式的 API），精准识别图片内容，自动生成通顺的中文描述作为文件名，并根据语义和规则将图片分发到合适的分类目录中。自带现代化的 Web 交互界面，支持一键处理海量图片。

---

## ✨ 核心特性

- 🤖 **AI 智能识别与重命名**：告别 `IMG_20230101.jpg`，自动转换为 `傍晚的城市海滨风景.jpg`。
- 📂 **动态分类系统**：根据 VLM 内容分析、文件名的强特征、图片比例等，将图片智能归入预设的 18 个清晰类别中（支持在前端自由编辑分类规则）。
- ⚖️ **高优先级比例检测**：内置专门针对“横屏（壁纸）”和“1比1（头像）”的规则，自动分离优质素材。
- 🌐 **现代化 Web UI**：基于 Vue 3 + FastAPI 构建的极简控制台。支持一键配置 API、管理分类、实时监控处理进度、查看错误日志。
- ⚡ **高性能并发与安全机制**：
  - 支持多账号并发请求 API，多线程加速 MD5 预扫描处理。
  - **双重去重系统**（MD5 校验 + 路径记录），随时可以一键清除缓存重新整理。
  - 文件防冲突设计：自动为重名文件添加递增序号。

## 🚀 运行模式

工具提供三种灵活的运行模式：
1. **默认模式**：分析重命名，并移动到对应的分类目录中。
2. **仅重命名模式**：分析重命名，但保留在原目录不动。
3. **整理散落图片**：深度扫描（递归子目录）未分类的文件，重新交给 AI 分析，并移动到已有的有效分类文件夹中，适合后期二次整理。

## 💻 安装与使用

### 方式一：使用独立安装包 (Windows)
如果您是普通用户，可以直接在 [Releases](../../releases) 页面下载最新版的 `.exe` 安装程序。
安装后双击桌面快捷方式即可打开浏览器进入控制台，**无需配置任何 Python 环境**。

### 方式二：通过源码运行 (开发者)

确保你已经安装了 Python 3.10+ 环境。

```bash
# 1. 克隆代码库
git clone https://github.com/qingxuandaoming/Picture.git
cd Picture/_app

# 2. 安装依赖
pip install -r requirements.txt

# 3. 运行服务
python main.py
# 运行后，程序会自动在浏览器中打开 http://127.0.0.1:8000
```

## ⚙️ 配置文件与数据存储

系统实现了彻底的数据分离，您的配置信息（如 API Key）和处理记录将安全地保存在系统的本地数据目录中，防止随代码意外泄露：
- **Windows**: `C:\Users\<用户名>\AppData\Local\qingxuandaoming\Picture`
- **macOS**: `~/Library/Application Support/qingxuandaoming/Picture`
- **Linux**: `~/.local/share/qingxuandaoming/Picture`

你可以在 Web 页面的「设置」中直接配置 API 密钥和要处理的照片根目录，所有修改将自动持久化保存。
